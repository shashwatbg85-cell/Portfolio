## 🎨 Visual System & Highlights

- **Theme:** Deep Cyber-Dark Mode (`#07070a` void background) with elevated Bento cards (`#111118`), subtle borders (`1px solid rgba(255, 255, 255, 0.08)`), and glassmorphism (`backdrop-filter: blur(16px)`).
- **Accent Glows:** Neon Indigo (`#6366f1`), Electric Cyan (`#06b6d4`), and Neon Green (`#10b981`).
- **Interactive Mouse Spotlight:** Dynamic radial glow that tracks cursor coordinates (`--mouse-x`, `--mouse-y`) across cards and borders.
- **3D Tilt Micro-Interactions:** Subtle physics-based card tilts on hover.
- **Real-Time IST Clock Widget:** Live ticking dual analog and digital clock synchronized with Indian Standard Time (`UTC +05:30`).
- **Live Terminal Telemetry:** Animated typewriter terminal cycling through status telemetry with one-click CLI copying.
- **Interactive Skills Matrix:** Real-time skill inspector callout displaying production build applications and animated proficiency progress bars.
- **CARGO-KARMA Logistics Simulation:** Interactive route progression (`Delhi Hub` → `Kanpur Depot` → `Lucknow Central`) with checkpoint state transitions and consignment switching.
- **Zero-Friction Contact Dock:** One-click email copy button with toast feedback and functional minimalist message dispatcher.
- **Web Audio API Synth:** Zero-dependency subtle cybernetic sound FX on clicks and toggles.

## 🛠️ Tech Stack

- **HTML5:** Semantic architecture, accessible forms, viewport ergonomics.
- **CSS3:** Asymmetric 12-column CSS Grid, Flexbox, CSS Custom Properties (`:root`), Keyframe Animations, Glassmorphism.
- **Vanilla JavaScript (ES6+):** Pure DOM manipulation, Web Audio API synth, IntersectionObserver ScrollSpy, IST clock engine.
- **Icons & Typography:** FontAwesome 6, Space Grotesk, Plus Jakarta Sans, Inter, JetBrains Mono.

## 🚀 Local Development

Clone the repository and open directly or run a local server:

```bash
# Clone repository
git clone https://github.com/shashwatbg85-cell/Portfolio.git
cd Portfolio

# Run lightweight server (Python)
python -m http.server 3000

# Or run with Node.js
npx serve .
```

Visit `http://localhost:3000` in your browser.
